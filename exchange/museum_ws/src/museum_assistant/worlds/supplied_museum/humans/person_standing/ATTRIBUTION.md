# Standing person visual

Source: `person_standing` from the OSRF Gazebo model database:
https://github.com/osrf/gazebo_models/tree/master/person_standing

Original model author: Marina Kollmitz. The model metadata states that the
character was created with MakeHuman (https://www.makehuman.org/).

The Gazebo model database distributes the asset under the Creative Commons
Attribution 3.0 Unported license (CC BY 3.0):
https://creativecommons.org/licenses/by/3.0/

Only `meshes/standing.dae` and the textures referenced by that mesh are copied
here. The visual is reused unchanged. The museum world retains the old torso
dimensions as a separate, simple collision primitive instead of using the
human mesh for collision.
